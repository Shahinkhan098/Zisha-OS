💻 পদ্ধতি খ: আপনার HP ল্যাপটপে লোকাল ISO বিল্ড / WSL2

আপনার HP পিসিতে Virtualization (VT-x) বর্তমানে বন্ধ (False) আছে। এটি চালু করতে:

  1. পিসি রিস্টার্ট দিয়ে শুরুর সাথে সাথে বারবার F10 চেপে HP BIOS-এ যান।
  2. Configuration / Advanced ➔ Virtualization Technology (VTx) ➔ Enabled করুন এবং F10 চেপে সেভ করুন।
  3. Windows চালু হলে Admin PowerShell-এ রান করুন:
wsl --install -d Debian

🔌 পদ্ধতি গ: পেনড্রাইভে পিসিতে সরাসরি ইনস্টল (Dual-Boot)

যেকোনো হালকা Debian 12 ISO বা Zisha OS ISO পেনড্রাইভে বুটেবল করে (Rufus/Ventoy দিয়ে):

  1. HP ল্যাপটপ রিস্টার্ট দিয়ে F9 চেপে USB Drive থেকে বুট করুন।
  2. ইন্সটল শেষে টার্মিনালে এক কমান্ডেই পুরো সিস্টেমকে Zisha OS 1.0-এ রূপান্তর করুন:
